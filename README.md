# TP-maquinadebusca
Trabalho prático para a matéria Programação e Desenvolvimento de Software II da UFMG para o primeiro semestre de 2023.

Aluno: José Vinícius de Lima Massarico.

Este projeto implementa um programa que faz a indexação e recuperação de documentos ou uma "Máquina de busca".

O projeto consiste em três arquivos principais:
- `indexador.h`: O cabeçalho da classe Indexador, que contém os métodos para construir o índice e recuperar documentos.
- `indexador.cpp`: A implementação da classe Indexador, com a lógica para construir o índice e realizar a recuperação de documentos.
- `main.cpp`: Um exemplo de uso da classe Indexador para construir o índice e realizar consultas.

Também está presente uma pasta, "documentos", que foi disponibilizada via Moodle para possíveis testes e consultas.
